# Allura Ecosystem — Organization Profile

This repository provides the public GitHub organization profile, its approved
wordmark asset, and shared GitHub community health files for
[`Allura-Ecosystem`](https://github.com/Allura-Ecosystem).

The organization profile rendered on the org landing page lives in
[`profile/README.md`](profile/README.md).

- Organization profile: [`profile/README.md`](profile/README.md)
- Approved wordmark: [`assets/allura-wordmark.png`](assets/allura-wordmark.png)
- Contribution guide: [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Security policy: [`SECURITY.md`](SECURITY.md)
- Code of conduct: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)

The community files are GitHub organization defaults. They are not Allura
product modules or ecosystem components.
